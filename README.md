# Hi, I'm Dias Ayazbai 👋

Full-stack developer focused on **analytics dashboards, CRM/ads integrations, bots and EdTech web products**.
I build things end-to-end: data pipelines (amoCRM, Meta Ads, Google Apps Script), backends (Python, Node), and fast, bilingual (KZ/RU) frontends.

> **Note on the work projects:** they were built for a real EdTech company. In this portfolio the brand is anonymized as **"EduApp"**, client names are replaced, and **every number on every dashboard is randomly generated** — no real business data is published.

**Stack:** Python · FastAPI · Flask · Node.js · React · Next.js · Vite · Tailwind · SQLite/Postgres · Google Apps Script · Telegram/Instagram/WhatsApp APIs · amoCRM · Meta Marketing API · Docker · Vercel · Solidity · Java · C++
